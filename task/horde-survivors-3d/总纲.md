# 3D 俯视角双人割草游戏执行计划

做一局能反复试玩的六分钟合作生存战。两人分别引怪、合流放技能，最后一起打 Boss。原型要回答两个问题：客机在延迟下走位、出刀、躲招是否跟手？两台机器各负责一半怪物后，哪一端能多承载多少只同屏活怪？

首个可玩版本只需要两名角色、一张地图、一把穿透飞刀、128 只怪和经验石。第一条验收路线是客机边后撤边攻击，房主从侧面补刀，两人抢到同一颗经验石，然后客机擦着预警圈的边缘躲开一次攻击。

## 玩法与范围

| 阶段 | 内容 | 可观察的结果 |
|---|---|---|
| 首个可玩版本 | Windows 上两个 Godot 进程通过原生 Netcode TCP 开房、加入。每人独立正交相机，固定方位，初始俯角取相对水平面约 60°。WASD 对应屏幕方向，在 XZ 平面移动，自动瞄准与走位独立 | 两人能分路，出屏的队友不拖动本地镜头。飞刀可在后撤时向追兵发射 |
| 现成人物与场地 | 复用 Shiftline 的 Quaternius 士兵及 Idle、Run、HitReact、Death 动画。队色用肩甲和脚圈显示。中央留空，两侧用矮护栏和箱子形成绕怪路线 | 同屏怪潮中能认出自己，看清冲锋线、经验石和地面预警。资源清单登记来源与许可 |
| 完整六分钟 | 0–2 分钟用慢速群怪教走位与拾取；2–5 分钟两侧加怪，冲锋精英逼变向；5–6 分钟中央出现 Boss，两侧残余怪群继续推进 | 形成分路与合流两种负载。击倒 Boss 胜利，双人倒地或六分钟到时 Boss 仍存活则失败 |
| 成长与合作 | 飞刀加穿透，圣环加半径，落雷加连锁数。任一人拾取都给团队加经验，升级时每位存活玩家各选一次，另一人可继续移动和作战 | 同时培养持续碰撞和瞬间多目标两种攻击。倒地者本局观战，幸存者可继续完成本局 |
| 占位内容 | 普通怪先用简单低模，精英用不同轮廓，Boss 用大体型和清晰的攻击预警 | 压测时能在同一套战斗逻辑上切换简化和完整显示 |
| 后续扩展 | 四人、更多角色与场景、局外养成、房主迁移 | 首轮投入集中在双人同引擎局域网和受控延迟环境 |

资源起点为[士兵模型](../../shiftline/assets/quaternius/Character_Soldier.gltf)、[现有角色场景](../../shiftline/actors/player/soldier.tscn)和[资源清单](../../shiftline/assets/sources.json)。清单将角色标为 Quaternius Toon Shooter Game Kit、CC0-1.0。新玩法复用模型与动画，在自己的场景里装配控制器。

## 主客机的职责

| 对象 | 决定权 | 即时反馈 |
|---|---|---|
| 玩家 | 标准玩法下本人控制移动、攻击起手和自己的受击、无敌、倒地。攻击者根据自己画面判定打中了哪些怪 | 移动、刀光、命中闪白、自己的受击反馈都在本地触发。房主玩家和客机玩家执行同一套战斗规则 |
| 普通怪 | 每只怪有一位负责人，推进追击、汇总所有玩家的有效伤害并发布血量。房主可在出生时按批分配负责人，合流时保留分配 | 两人能同时打中同一只怪；每笔有效伤害结算一次，每只怪只死亡一次 |
| Boss 与全局 | 房主负责 Boss、刷怪、局时、掉落、共享经验、升级资格和胜负。Boss 提前发出带生效时刻的预警，每个玩家自行判定是否中招 | 玩家在本机看到自己已躲开就成功闪避；两人同抢经验石只涨一次团队经验 |

A/B/C 三档只改变移动与怪群的模拟归属。A 由房主模拟所有移动和怪物，B 把角色移动交给本人，C 再把约一半普通怪分给客机。三档均让攻击者判定打怪、受击者判定自身受伤。实际路由、去重和接管规则见[战斗同步契约](契约/战斗同步.md)。
